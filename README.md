LOWTIDE is a round-based 5v5 tactical FPS built with Three.js on an original dusk-harbour map. The Breakers plant a breach charge at site A (Fuel Farm) or site B (Crane Pad) while the Wardens defend and defuse, with a buy phase and economy, five weapons, armour, frag/flash/smoke grenades, and bot teammates and opponents with roles who path a waypoint graph, hold angles and rotate on contact info. Full HUD with minimap, killfeed and buy menu; fixed 60 Hz simulation decoupled from rendering; synthesized WebAudio throughout; no build step — the game is plain static files with three.js vendored in.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — click to lock the pointer and play
```
